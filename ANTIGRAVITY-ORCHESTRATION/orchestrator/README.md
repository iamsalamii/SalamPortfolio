# Moteur d'Orchestration Multi-Agents (orchestrator/)

Ce répertoire contient l'intelligence opérationnelle, les algorithmes de décision, les règles d'engagement et les flux de travail standardisés du système `ANTIGRAVITY-ORCHESTRATION`.

---

## Rôle du Système d'Orchestration

L'orchestrateur est le cerveau du système de développement. Il coordonne les 17 profils d'agents spécialisés sans jamais tomber dans le piège de la bureaucratie ou du sur-engineering.
